# Security Policy

## Supported Versions

Only the latest release of Wallpaper Sync is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v3.3+   | :white_check_mark: |
| < v3.3  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by opening a GitHub Issue or contacting the maintainers directly at debanjangamedu@gmail.com. We will investigate the issue and address it as quickly as possible.
